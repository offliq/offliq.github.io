What's new in V1.2

"See-Saw" Memory Manager

OFFLIQ dynamically juggles models. A lightweight 'Gatekeeper' stays awake for instant chat. When coding, it loads the Heavy model, executes, and instantly terminates to free up 100% of system RAM.

Cryptographic Plugin Vault

Drop custom Python scripts (like Azure scanners) into the plugins folder. OFFLIQ locks them with a SHA-256 signature. If altered by malware, execution is permanently blocked.

Hardware Telemetry Shield

Dynamic OS querying prevents junior techs from crashing their workstations. If an attempt is made to allocate more memory than physically available, the system intercepts and blocks it.

Tiered Vector RAG

Drag and drop entire company IT manuals or codebases into the sources folder. OFFLIQ silently indexes them locally to write solutions customized to your specific internal standards.
